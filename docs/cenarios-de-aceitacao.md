# Cenários de aceitação

Estes cenários especificam o comportamento esperado; ainda não são testes executados de uma aplicação.

| Cenário | Resultado esperado |
| --- | --- |
| PC com periféricos incluídos | Um grupo principal; cálculo de uma caixa |
| PC com monitor incluído | Monitor no grupo principal |
| PC com cadeira incluída | Grupo principal e pacotes próprios da cadeira |
| Mesa ou pé de mesa | Pacotes próprios do fabricante |
| Monitor, suporte ou nobreak avulso | Pacotes próprios, fora da caixa do PC e dos avulsos agrupados |
| Teclado, mouse e fone avulsos | Mesmo grupo de avulsos; caixa separada do PC |
| Mesmo SKU incluído e avulso | Linhas e destinos distintos conforme origem |
| Cooler substituído | Somente a peça final e suas embalagens aplicáveis |
| Ventoinhas adicionadas à configuração | Vínculo com o PC preservado; tratamento conforme preparação real |
| Dois PCs do mesmo SKU com alterações diferentes | Identificadores e grupos principais independentes |
| Memória e SSD acondicionados na caixa da placa-mãe | Sem somar seus envelopes novamente no volume externo |
| Falta de recipiente para item agrupado internamente | Pendência para revisão |
| Uma unidade com dois pacotes de fábrica | Dois volumes próprios |
| Duas unidades com dois pacotes de fábrica cada | Quatro volumes próprios |
| Medidas ausentes | Grupos visíveis; sugestão operacional bloqueada |
| Medidas fictícias | Simulação identificada; aprovação operacional bloqueada |
| Itens ocupam exatamente 85% | Critério de reserva atendido; ainda validar encaixe e peso |
| Itens ocupam mais de 85% | Caixa rejeitada pela reserva mínima |
| Volume total suficiente, mas um objeto não cabe | Caixa rejeitada pelo encaixe |
| Peso supera capacidade de carga | Caixa rejeitada |
| Nenhuma caixa compatível | Exceção para revisão, sem divisão automática |
| Embalagem ou composição muda | Plano anterior não reutilizado automaticamente |

## Exemplos matemáticos fictícios

Caixa com 60 × 50 × 50 cm internos: 150 litros. Limite de ocupação: 127,5 litros. Reserva mínima: 22,5 litros.

Esses números são exclusivamente didáticos; não representam caixas ou produtos da Pichau. Mesmo abaixo do limite, o encaixe físico continua obrigatório.
